# Slides2Handouts

将 PowerPoint 幻灯片排成可打印的 PDF 讲义。默认 A4 纵向，左侧三张原稿、右侧批注、底部页码。界面使用 PyQt6，控件、菜单和步进箭头样式来自本机 CrystalX 的样式规则。

## 安装与启动

需要 Windows 10/11、Python 3.11 或更高版本、已激活的桌面版 Microsoft PowerPoint。

双击 install.vbs 安装依赖并创建快捷方式，随后双击 launch.vbs 或 Slides2Handouts 快捷方式。项目已有 .venv 时安装程序会更新依赖。启动问题记录在 startup.log，运行异常记录在 runtime.log。

开发环境可运行 .venv\Scripts\python.exe main.py。

## 页面与原稿

“文件 → 导入 PPTX”打开课件。导入窗口居中显示进度。原稿单击定位其讲义位置，双击预览原始幻灯片。Ctrl 或 Shift 多选后点击“插入选中原稿”，可重复使用幻灯片。

中央工具栏水平居中，左右箭头换页，输入页码后回车直达。Page Up / Page Down 可换页。缩放百分比以适应窗口为 100%。中央滚轮缩放，中键拖动平移。

左下页面树支持跨页拖动。页面菜单中的“移到下一页并顺延”会把满页末尾的幻灯片继续向后移。每页三张时，将第 3 张移到下一页得到 [1,2]、[3,4,5]、[6]。

## Slides 区域尺寸与间距

进入“布局 → 页面 / Slides 区域”，在右侧“Slides 内容区域”设置左、上、宽、高。数值单位为点，72 点等于 1 英寸。“恢复自动区域”根据纸张和边距重新计算区域。

“幻灯片间距”控制自动排版中相邻行的空隙；“排列”支持纵向、横向和网格。每张幻灯片保持原始比例。每页张数控制新导入以及“从选中原稿重新分页”的分组容量。

拖动页面中的幻灯片可手动定位，右下角手柄可调整尺寸。按 Shift 拖动锁定水平或垂直方向，按 Shift 缩放文字框保持比例。已有手动坐标的幻灯片可通过“布局 → 恢复本页自动布局”重新使用区域和间距设置。

## 属性、文字与颜色

属性变化即时生效。预览在独立进程中生成，连续输入会合并刷新，撤销也会合并连续编辑。

属性面板支持滚轮滚动。滚轮经过数值框和下拉框时仍滚动属性面板，不改变值。数值可直接输入或点上下箭头。

颜色字段显示圆角色块，点击进入调色盘。调色盘内的“十六进制”框可输入 #RRGGBB。颜色代码不出现在属性色块右侧。

“文字 → 添加文字”建立独立文字框。双击文字定位到右侧内容编辑。支持字体、字号、加粗、斜体、下划线、颜色、水平对齐、顶部/居中/底部垂直对齐、背景、边框和旋转。

Ctrl+C / Ctrl+V 复制粘贴对象，Delete 删除，Ctrl+Z / Ctrl+Y 撤销重做。文字输入框保留自己的编辑快捷键。

## 每页标题

“文字 → 本页标题”编辑标题。默认勾选“与上一页保持一致”，继承内容用灰色表示，并可直接编辑。编辑后自动退出继承，形成当前页的独立标题。后续仍勾选继承的页面随之使用这个标题。

勾回继承即可恢复上页标题。第一页继承模板标题。“显示”可隐藏本页标题，并按继承关系传递给后续页面。“文字复制到页面范围”支持指定多页使用同一文字内容。

## 页码与批注

页码位于“布局 → 页码样式”和“布局 → 本页编号”。

格式可使用 {n}、{n:02d}、Page {n} 或 {chapter}{sep}{sub}。在章节首页将一级编号设为 2、二级编号设为 1，即从 2.1 编起。支持指定显示文字和隐藏当前页页码。

默认页码框距底边 16 点，自动内容与页码框相隔至少 10 点。手动坐标保留用户设置，重叠或越界会在状态栏和导出前提示。

“布局 → 添加批注区”建立独立批注区域，支持背景、边框、空白、横线和网格。

## 工程、模板与 PDF

工程 JSON 保存原稿路径及 SHA-256、页面分组、对象、标题继承关系和全部排版参数。原始 PPTX 要与工程一起保留，移动后打开工程可重新定位。

模板保存纸张、区域、全局批注和默认标题等 settings。模板可用于其他课件。旧版本工程可以直接读取，已有模板标题作为继承起点。

导出使用 PowerPoint 原始 PDF 进行矢量拼版。原稿中的位图仍作为位图保留。预览和导出共用排版与文字绘制函数。打印选择实际大小。

## 验证

测试依赖 python-pptx。运行 .venv\Scripts\python.exe -m unittest discover -s tests -v。
Windows 启动测试使用 powershell -ExecutionPolicy Bypass -File tests/launch_smoke.ps1。

当前仅支持 PowerPoint 转换后端。复杂效果的保留质量取决于 PowerPoint 的 PDF 输出。真实课件及打印机仍可能呈现字体替换或图像差异。

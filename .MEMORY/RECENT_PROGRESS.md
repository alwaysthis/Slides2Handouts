# 最近进展 · 2026-11-25

0.6.0 已将主 GUI 由 Tk 迁到 PyQt6。窗口移动、弹出菜单、控件和颜色对话框使用 Qt。移除了旧 Tk 标题栏与图片主题代码。

已增加即时编辑、居中工具栏、属性滚动、数值滚轮保护、页面滚轮缩放、Shift 轴向移动、Slides 区域宽高与间距、文字垂直对齐、按页继承标题。页面渲染移到独立进程，避免 PDF 合成阻塞鼠标与键盘事件。

开发测试发现并修复标题复制值未写回、垂直排版测量返回类型、预览中文编码及 QWidget.window 方法命名冲突。旧工程 schema 仍为版本 1，新增字段可选，读取时使用默认值。

最终 11 项测试通过，涵盖真实 PowerPoint 转换及工程往返。VBS 启动通过，另外使用 pythonw 实际启动验证了异步 PDF 预览。已保存工作区、继承标题、调色盘的实机截图。预览子进程显式使用 python.exe，通过 QProcess 管道通信，避免 pythonw 缺少标准流。

0.7.0 引入区域划分和节级对象，导出和异步预览使用同一套布局。右键移动产生空槽，PDF 跳过空槽。新增奇偶页镜像、空槽导出和页眉继承测试。

## 2026-11-26

完成区域划分、奇偶页镜像、分节页眉页脚、文本与编号样式、目录和原稿输出顺序联动。左栏支持上下分栏及实际输出缩略图。应用内弹窗共享圆角外框与标准按钮，关闭前确认，PDF 导出在状态栏显示进度。Windows 单实例启动会唤起已有窗口。

讲义工程继续使用版本 1 JSON，保存时增加内嵌 PPTX。旧工程打开后再保存即可升级。已验证真实 PPTX 的迁移以及移除外部原稿后的打开和导出。
